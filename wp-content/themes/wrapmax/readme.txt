=== Wrapmax ===
Requires at least: 6.2
Tested up to: 6.6
Requires PHP: 7.4

== Description ==
Wrapmax is a Custom Packaging & Branding Agency theme template for WordPress that supports full site editing and is fully compatible with the Gutenverse plugin. Wrapmax is perfect for Custom Packaging & Branding Companies, Packaging Suppliers, Packaging Solutions and any other businesses in the Manufacturing Industry. You can use the core version and the included Gutenverse to easily create the website you want. We want to make sure that you have the best experience using WordPress to edit your site.
